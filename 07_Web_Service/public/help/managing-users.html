Managing Users (for ISAF Admins)

For your company's ISAF Admin: how to set up login accounts, add and manage the people who use ISAF, and use the seats in your license. Everyone else only needs the User Guide.

1. How login accounts work

  • Each person signs in with their own username and password. A login is personal: it may not be shared.
  • Your license gives you a number of seats. A seat is one active account. MX Aero issues your seats as seat codes, which you enter in the app; the app checks them itself, without an internet connection.
  • There are two roles. Admin: manages accounts and seats and sees the Administration tab; the banner is darker and shows "Admin" before the version. User: works on programs.
  • A login can be signed in on one computer at a time. Signing in on another computer signs the first one out.
  • The app records every account created, disabled or enabled, every role change and every seat code entered, with the date and the seats in use. This history is part of the usage report your license sends to MX Aero.

2. Set up login accounts (once)

  1. Ask MX Aero for your Admin seat code. It is a long text that starts with ISAF-SEAT.
  2. Open the app and go to Administration → Login accounts → Set up login accounts.
  3. Paste the whole Admin seat code, choose your username, enter your full name and a password (at least 8 characters), and select Create Admin account.
  4. You are signed in as the Admin. From now on everyone signs in with their own account, and the access keys people used before stop working.
Before you start, make sure the people who use ISAF will get their accounts soon after: once the first account exists, nobody can use the app with an access key any more.

3. Add a person

  1. Open Administration → Manage accounts and seats (or your account menu, top right → Accounts).
  2. The top of the window shows Seats in use: X of Y. You can add a person while a seat is free.
  3. Enter a username (3 to 40 letters, digits, dots, dashes or underscores, for example jsmith), the person's full name, optionally their email, and the role (User or Admin). Select Add account.
  4. The app shows a temporary password once. Give it to the person privately. At their first sign-in they must choose their own password.

5. Seats

  • All seats in use? Disable an account that is no longer needed, or ask MX Aero for more seats.
  • New seats from MX Aero arrive as a seat code. In the Accounts window, paste it under Add a seat code from MX Aero and select Add seat code. The seat count goes up at once. Each code can be entered once.
  • Reassigning a seat: your license allows a seat to be given to another person when its holder leaves the company or changes role, or at most once every 30 days. Rotating seats or sharing logins so that more people use ISAF than your seats allow is not permitted.
  • Seat codes entered in the Accounts window lists every code, its seats and who entered it.

6. If something goes wrong

MessageWhat to do
"This is not an ISAF seat code" or "This seat code is not valid"Copy the whole code again, from ISAF-SEAT. to the end, without spaces or line breaks.
"The first account needs an Admin seat code"The code you entered adds seats but cannot create the Admin account. Ask MX Aero for the Admin seat code.
"This seat code is for another ISAF license"The code belongs to another license. Ask MX Aero for a code for yours.
"This seat code has already been entered"It is counted already; nothing to do.
"All N seats are in use"Disable an account, or add a seat code from MX Aero.
"You were signed out because your account signed in on another computer"The same login was used elsewhere. If that was not the person, reset their password.
"Too many wrong passwords"Wait 15 minutes, or reset the person's password.
