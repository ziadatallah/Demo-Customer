Standard build

With Document Control on, use the program’s saved documents where available. A document not yet in the repository starts from an ISAF master. With Document Control off, documents are generated from ISAF masters.

New template drafts

Create separate candidates from ISAF master templates for review. This does not replace or change the program’s saved documents.

To compare a draft

After the build, open Program Documents, select the document, and download both the candidate and current saved version from Details / History. Compare them in Word using Review → Compare, then return to the document record to accept or reject the candidate.

Document type guide

Use these recommended codes or adapt them to your company. They cover internal documents as well as certification and contractual deliverables; they are ISAF defaults, not mandatory industry codes. Delivery obligations are separate from document type. A PSAC is a particular plan; PLN is its numbering category.

Code *Meaning *Examples / intended useAction

Keep only the categories your organization needs. Codes must be unique. Generation assigns document categories automatically. Standard category codes remain PLN, STD, SPEC, RPT, CHK, PROC and REG; additional custom codes describe internal documents. Editing this guide does not reclassify existing templates.
